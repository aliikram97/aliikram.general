Class: Navigation

Integrating Robot Physical Dimensions into Path Planning

A hybrid robot-aware path planning system that integrates robot dimensions directly into navigation using an initial binary map. Traditional path-planning treats the robot as a unit point, ignoring its physical size and shape, which can cause collisions or inefficient routing. This method expands obstacle boundaries according to the robot's actual dimensions, so any standard path-planning algorithm inherently accounts for robot size — no algorithm changes or external sensors required.
