Featured Projects

Seven engagements, with links and demos.

Integrating Robot Physical Dimensions into Path Planning

A hybrid robot aware path planning system that integrates robot dimensions directly into navigation using an initial binary map. Traditional path planning treats the robot as a single point, ignoring its physical size and shape, which can cause collisions or inefficient routing. This method expands obstacle boundaries according to the robot's actual dimensions, so any standard path planning algorithm accounts for robot size without changes to the algorithm or added sensors.

View repository

Talk2TextTranslate, a Transcription and Translation Pipeline

An audio transcription and translation pipeline built to process long recordings efficiently. It converts speech to text using Google's Speech Recognition service, then translates it into multiple languages with Googletrans. Built for multilingual communication, content localization, and accessibility.

View repository

Multilingual OCR System

A local, AI driven OCR and translation pipeline that extracts, translates, and summarizes text from images without cloud processing. It detects multilingual content with high precision, translates it into the user's preferred language, and generates a short summary, all while keeping data on the device.

Thermal Object Tracking

A high performance infrared tracking system for long range thermal detection up to three kilometers, optimized for real time recognition on embedded hardware such as NVIDIA Jetson. A custom occlusion detection algorithm maintains continuous tracking through dense thermal clutter, built for surveillance, defense, and industrial monitoring.

Adaptive Cruise Control
